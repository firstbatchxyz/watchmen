Prompt-intent map{% if scope_label %} — {{ scope_label }}{% endif %}

An exploratory view: every genuine prompt you typed, embedded with a local model and laid out so similar asks sit nearby. Good for spotting regions of work and browsing; not a precise instrument — t-SNE distances and cluster shapes are approximate, so read neighbourhoods, not coordinates. The actionable signals live in Metrics (recurring mistakes, the work matrix). Hover a point to read it; scroll to zoom, drag to pan.
